# かけ算ひっ算 れんしゅう

小学3〜4年生向けの、かけ算の筆算を練習する静的Webサイトです（HTML / CSS / JavaScript のみ。サーバー不要）。

## できること

- けた数：2×1 / 3×1 / 2×2 / 3×2、問題数 5・10・20、くり上がり あり／なし／どちらも
- 筆算の形で1けたずつ入力（テンキー・キーボード対応）。2けた×2けたは「とちゅうの計算」マスつき
- けいさんスペース（指やペンで書ける。くろ・あか・けしごむ）、くり上がりメモ用の小マス
- こたえあわせ：1問ずつ／さいごにまとめて、○×、まちがえたけたを赤く表示、正しいやり方を表示
- 制限時間（3・5・10分）、タイム計測、ベストタイム（全問正解のとき）
- 連続正解、全問正解でスタンプ＆ごほうび
- まちがえた問題だけ やり直し（ブラウザに保存）
- きろく（せいかい率グラフ・履歴）はブラウザの localStorage に保存
- 印刷用プリント（A4、10問／20問、答えページつき）

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作る（例：`kakezan-hissan`）
2. `index.html` `style.css` `app.js` `README.md` をリポジトリの直下にアップロード
3. リポジトリの Settings → Pages → Branch を `main` / `(root)` にして Save
4. 数分後、`https://ユーザー名.github.io/リポジトリ名/` で使えます

## メモ

- 記録は、使っている端末・ブラウザごとに保存されます（端末をまたいだ共有はされません）
- 「きろく」画面の「ぜんぶ けす」で記録を消せます
